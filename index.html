Introduction to I/O in Java

Input/Output (I/O) in Java refers to the process of reading data from a source and writing data to a destination.

Input

Data coming into a program, such as text from a file, a keyboard, or a network connection.

Output

Data leaving a program, such as text saved to a file or printed on the console.

Why I/O is important

Programs are only useful when they can receive data and keep their results. I/O lets applications load settings, process files, store records and talk to other systems.

How Java uses streams

Java treats data as a stream: a continuous sequence that flows from a source into the program, or from the program to a destination. The classes in the java.io package provide these streams.

Byte Streams

Byte streams read and write data exactly as it is stored, one byte at a time. They do not interpret the data, so they work for any kind of file.

InputStreamOutputStreamFileInputStreamFileOutputStreamBufferedInputStreamBufferedOutputStream

Commonly used for: images, audio, video, PDF files and other binary data.

ByteStreamExample.java
import java.io.*;

public class ByteStreamExample {
    public static void main(String[] args) throws IOException {

        FileInputStream input = new FileInputStream("input.txt");
        FileOutputStream output = new FileOutputStream("output.txt");

        int data;

        while ((data = input.read()) != -1) {
            output.write(data);
        }

        input.close();
        output.close();

        System.out.println("File copied successfully.");
    }
}

Character Streams

Character streams are designed for handling text data and characters. They convert bytes to Unicode characters for you, so text in any language is read correctly.

ReaderWriterFileReaderFileWriterBufferedReaderBufferedWriter

Why they help: they handle character encoding automatically, and buffered versions can read a whole line at a time, which makes text files easier to process.

CharacterStreamExample.java
import java.io.*;

public class CharacterStreamExample {
    public static void main(String[] args) throws IOException {

        FileReader reader = new FileReader("input.txt");
        FileWriter writer = new FileWriter("output.txt");

        int data;

        while ((data = reader.read()) != -1) {
            writer.write(data);
        }

        reader.close();
        writer.close();

        System.out.println("Text copied successfully.");
    }
}

Java Examples

Reads a file byte by byte and prints each byte as a character.

ReadBytes.java
import java.io.*;

public class ReadBytes {
    public static void main(String[] args) throws IOException {
        FileInputStream in = new FileInputStream("input.txt");
        int b;
        while ((b = in.read()) != -1) {
            System.out.print((char) b);
        }
        in.close();
    }
}

Expected result: the contents of input.txt are printed on the console.

Converts a string into bytes and writes them to a file.

WriteBytes.java
import java.io.*;

public class WriteBytes {
    public static void main(String[] args) throws IOException {
        FileOutputStream out = new FileOutputStream("data.txt");
        String text = "Hello, Java I/O!";
        out.write(text.getBytes());
        out.close();
        System.out.println("Data written successfully.");
    }
}

Expected result: a file named data.txt is created containing "Hello, Java I/O!".

Reads a text file one line at a time, which is faster and simpler than reading single characters.

ReadLines.java
import java.io.*;

public class ReadLines {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new FileReader("input.txt"));
        String line;
        while ((line = br.readLine()) != null) {
            System.out.println(line);
        }
        br.close();
    }
}

Expected result: every line of input.txt is printed on its own line.

Real-World Use Cases

Reading configuration files

Applications load settings such as database addresses or preferences from files when they start.

Processing text files

Programs search, count or transform the text in documents, CSV files and reports.

Copying images and documents

Byte streams copy files exactly, so pictures and PDFs stay intact.

Handling uploaded files

Web applications read uploaded data as a stream and save it to storage.

Reading logs

Tools read log files line by line to find errors and monitor activity.

Data processing

Large datasets are read in pieces through streams, so they do not need to fit in memory.

Conclusion

Java I/O streams give programs a structured way to read and write data. Byte streams handle raw binary data such as images and audio, while character streams handle text and Unicode. Understanding both helps developers choose the right approach for the type of data they work with.

Choose the right stream based on the type of data you need to handle.
